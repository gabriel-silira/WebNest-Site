# WebNest — Site Institucional

Site oficial da **WebNest**, empresa de desenvolvimento web que cria experiências digitais modernas, rápidas e responsivas para marcas que querem crescer.

O projeto apresenta a empresa, seus serviços, a forma de investimento, projetos selecionados e canais de contato. Não é um site demonstrativo: é a presença institucional da própria WebNest.

**Versão 1.0**

---

## Sobre o site

O site foi construído para comunicar a proposta da WebNest com clareza e ajudar empresas a encontrar o formato digital mais adequado para o seu próximo passo.

Entre os conteúdos apresentados estão:

- Serviços de criação de sites e sistemas web.
- Opções de investimento e escopos resumidos.
- Projetos demonstrativos de diferentes segmentos.
- Case do Hoody Bot, projeto real da WebNest.
- Canais de contato por WhatsApp, Instagram e e-mail.
- Página de privacidade.

## Estrutura do projeto

```text
WebNest-Site/
├── public/             # Arquivos públicos, incluindo o favicon
├── src/
│   ├── assets/         # Imagens otimizadas usadas pelo site
│   ├── components/     # Componentes reutilizáveis da interface
│   ├── data/           # Conteúdos de projetos, serviços e contato
│   ├── hooks/          # Hooks compartilhados
│   ├── pages/          # Páginas e rotas do site
│   ├── App.jsx         # Estrutura principal da aplicação
│   ├── main.jsx        # Ponto de entrada do React
│   └── styles.css      # Estilos globais
├── package.json
└── vite.config.js
```

## Desenvolvimento local

### Pré-requisitos

- Node.js 24
- npm

### Instalação

```bash
npm install
```

### Servidor de desenvolvimento

```bash
npm run dev
```

### Build de produção

```bash
npm run build
```

### Pré-visualização do build

```bash
npm run preview
```
